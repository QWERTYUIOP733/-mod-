## 功能介绍

### 核心功能

1. **221色实心色块**
   - 9个色系（A、B、C、D、E、F、G、H、M），共221种颜色
   - 程序染色，色标准确
   - 物品名称双行显示：色号编号 + RGB值

2. **色板UI（快捷键 G）**
   - 颜色选取：浏览全部221色号网格，点击获取一组（64个）
   - 色号输入：输入色号（如 A1、B5、M3）自动放入快捷栏，支持批量输入
   - 支持连续选择，不关闭界面

3. **创造模式标签页**
   - 按字母系列分类（A、B、C、D、E、F、G、H、M）
   - 标签页名称仅为字母，简洁清晰

4. **七彩粉末（通用合成材料）**
   - 任意原版染料可合成七彩粉末
   - 七彩粉末可合成任意颜色的色块（一组64个）
   - 合成结构：染料 → 七彩粉末 → 任意色块

5. **方块染色台**
   - 功能类似原版工作台，但只能合成模组内物品
   - 3x3合成网格 + 结果槽
   - 右侧颜色选择面板，支持滚动浏览
   - 面板宽度自适应，始终在右侧
   - 支持七彩粉末合成模式

### 命令

- `/mardp give <色号>` - 给予指定色号的方块
- `/mardp find <颜色>` - 查找最接近的颜色

## 安装方法

1. 确保已安装 Minecraft 1.20.1 和 Forge 47.2.0+
2. 将 `mods/彩色方块扩展-1.2.0.jar` 复制到 `.minecraft/mods/` 文件夹
3. 启动游戏

## 使用说明

### 获取色块

1. **创造模式**：在创造模式物品栏的"彩色方块扩展"标签页中找到对应色系
2. **色板UI**：按 G 键打开色板，点击颜色选取或输入色号
3. **合成**：
   - 用任意染料合成七彩粉末
   - 用七彩粉末合成任意色块（在方块染色台中选择颜色）

### 方块染色台使用

1. 放置方块染色台并右键打开
2. 在3x3网格中放入七彩粉末
3. 在右侧颜色面板中选择想要的颜色
4. 从结果槽取出合成的色块

## 兼容性

- 客户端和服务端都需要安装
- 与其他Forge模组兼容
- 不修改原版游戏内容

## 技术细节

- 所有色块使用程序染色（BlockColor + ItemColor），无需单独贴图
- 色块ID格式：`mard_pixel:mard_<色号>`（如 `mard_pixel:mard_a1`）
- 七彩粉末ID：`mard_pixel:mard_pigment`
- 方块染色台ID：`mard_pixel:mard_crafting_table`
