# 更新日志

## v1.2.0 (2026-09-06)

### 新增功能

1. **方块染色台**
   - 全新的合成用方块，功能类似原版工作台
   - 只能合成模组内物品
   - 3x3合成网格 + 结果槽 + 玩家背包
   - 右侧颜色选择面板，支持鼠标滚轮滚动
   - 面板宽度自适应窗口大小，始终在右侧
   - 支持七彩粉末合成模式

2. **七彩粉末（通用合成材料）**
   - 任意原版染料（16种）可合成七彩粉末
   - 七彩粉末可合成任意颜色的色块（一组64个）
   - 合成结构：染料 → 七彩粉末 → 任意色块

3. **色板UI增强**
   - 颜色选取页面支持连续选择（不关闭界面）
   - 色号输入支持批量输入多个色号
   - 合成模式提示

### 修复问题

1. **给予物品消息显示"空气"的bug**
   - 原因：`Inventory.add()` 会清空传入的ItemStack，导致之后获取名称时显示"空气"
   - 修复：在调用add()之前先保存物品名称

2. **UI界面品牌名残留**
   - 移除所有硬编码的品牌显示名称
   - 模组更名为"彩色方块扩展"

3. **菜单槽位注册问题**
   - 修复客户端构造函数未注册槽位导致的IndexOutOfBoundsException

4. **方块实体空指针崩溃**
   - 修复漏斗插入物品时触发的空指针崩溃
   - 新建SafeCraftingContainer类独立实现CraftingContainer接口

5. **合成材料消耗问题**
   - 修复七彩粉末模式下错误消耗所有材料的问题

### 优化改进

1. **UI自适应**
   - 颜色选择面板宽度动态计算（110px~150px）
   - 面板始终在主界面右侧，不再自动切换
   - 每次渲染时重新计算面板宽度

2. **代码优化**
   - 移除自定义颜色功能及残留代码
   - 统一物品给予逻辑
   - 完善空值检查
