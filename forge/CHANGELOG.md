# 更新日志 (Changelog)

## [3.0.0] - 2026-10-10

### Minecraft 26.3（Forge 66.x / Java 25）
- 适配 26.3 的事件总线注册、方块与方块实体、网络通道等变更。
- 适配 SDL3 鼠标输入与 GuiGraphics 文字渲染；G 键色板在各窗口尺寸下与既有版本保持一致，说明面板文字按整数档缩放并整块居中。
- 修复按 G 键时可能自动向物品栏投放一组方块的问题；高频获取提示改为动作条显示，不再占用聊天记录。
- 功能与 Fabric 版一致：221 色块、七彩粉末、方块染色台、9 个创造标签页、批量色号输入、`/mardp` 命令。

## [2.1.0] - 2026-10-09

### Minecraft 1.21.4（Forge 54.x / Java 21）
- 修复 1.21.2+ 合成书里 16 种染料配方未归组的问题（现折叠为同一个条目，不再每种染料各占一格）。
- 适配 1.21.4 的物品颜色数据驱动与配方格式变更。

## [2.0.0] - 2026-10-08

### Minecraft 1.21.1（Forge 52.x / Java 21）
- 适配 1.21.1 的 CustomPacketPayload 网络机制，修复进入游戏时网络通道相关崩溃。
- 配方更新为 1.21.1 格式（单数 `recipe/` 目录、结果使用 `id` 字段）；清理被染色台选色功能取代的旧配方。
- 空手右键打开染色台、方块实体存档、物品提示框、资源定位方式等适配；G 键说明面板随窗口自适应缩放。
- 补充模组图标。

## [1.2.3] - 2026-09-18

### 构建（无功能变化）
- Forge loader 47.1.0 → 47.4.23，ForgeGradle 固定 6.0.54，移除不可用的镜像仓库。
- 注意：本版本的发布资产与 v1.2.2 完全相同（同一 SHA-256），`mods.toml` / `build.gradle` 的版本号仍为 1.2.1，属命名事故，详见 RELEASE.md §7。

## [1.2.2] - 2026-09-08

### 修复
- 染色台选色面板与 JEI 物品管理器位置冲突：面板固定到左侧并做屏幕边界检测，宽度 80–130 px 自适应。
- 修复 `colors/mard_295.json` 的 BOM 头导致 GitHub Actions 构建失败的问题。

## [1.2.1] - 2026-09-27

### Forge版本
- 修复G键UI说明面板内容显示不全的问题
- 精简按钮一简介，与按钮二保持一致
- 修复Java文件BOM字符导致的构建失败
- 优化UI布局自适应

### Fabric版本

- 精简按钮一简介，与按钮二保持一致
