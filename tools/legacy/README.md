# 历史脚本说明（tools/legacy）

这里存放的是**一次性维护脚本**，不属于构建链路，CI 与 Gradle 都不会调用：

| 文件 | 用途 | 状态 |
|---|---|---|
| `add_copyright.py` | 批量为 Java 文件添加版权头 | 一次性使用完毕，保留备查 |
| `fix_info_panel_v2.py` | 批量改 G 键色板「使用说明」面板的绘制代码 | 一次性使用完毕，保留备查 |
| `simplify_button1.py` | 批量精简色板按钮一的简介文案 | 一次性使用完毕，保留备查 |

约定：

1. 新的一次性脚本也放这里，**不要放仓库根目录**；
2. 脚本头部请注明「一次性」以及它改了什么，避免半年后被误当成构建脚本；
3. 真正需要长期维护的脚本（资源生成、校验）放在 `tools/` 根目录，并在 `.github/workflows/` 里被调用。
