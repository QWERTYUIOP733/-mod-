# 彩色方块扩展 Mod（Minecraft 1.20.1 · Forge）

一套将 **221 基础色**标准色卡做成 Minecraft 实心色块的像素画 Mod，支持七彩粉末通用合成和方块染色台。

> **当前版本仅支持 Forge 加载器。**

- 版本：v1.2.0
- 游戏版本：Minecraft 1.20.1
- 加载器：Forge 47.2.0+
- 许可证：MIT
- 作者：Pixel Team

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 221 基础色块 | 9个色系（A-H/M），每个色号一个实心色块，程序染色，色标准确 |
| 创造标签页 | 按字母系列分类（A、B、C、D、E、F、G、H、M） |
| 色板UI（快捷键 **G**） | 颜色选取 + 色号输入，支持连续选择和批量输入 |
| 七彩粉末 | 通用合成材料，任意原版染料可合成，可合成任意色块 |
| 方块染色台 | 专用合成方块，3x3合成网格 + 右侧颜色选择面板 |
| 物品名称双行显示 | 第一行：色号编号（白色）；第二行：RGB 值（灰色） |
| 命令系统 | `/mardp give <色号>` 给予物品，`/mardp find <颜色>` 查找最近色号 |

## 安装

### Forge 端

1. 安装 Minecraft 1.20.1 + Forge 47.2.0+
2. 把 `彩色方块扩展-1.2.0.jar` 放入 `mods/` 文件夹
3. 启动游戏

---

## 使用方法

### 色板UI（推荐）

- 按 **G** 打开色板界面
- **颜色选取** — 浏览全部221色号网格，点击任意色号 → 对应物品一组（64个）进入背包，支持连续选择不关闭界面
- **色号输入** — 在输入框中输入色号（如 A1、B5、M3），支持批量输入多个色号，回车确认 → 自动放入快捷栏

### 七彩粉末合成

1. **合成七彩粉末**：在工作台中放入任意一种原版染料（白色、红色、蓝色等16种染料），即可合成七彩粉末
2. **合成色块**：在方块染色台中放入七彩粉末，在右侧颜色面板选择想要的颜色，从结果槽取出合成的色块（一组64个）

### 方块染色台

1. 在创造模式物品栏中找到"方块染色台"并放置
2. 右键打开合成界面
3. 在3x3网格中放入七彩粉末
4. 在右侧颜色选择面板中滚动浏览并点击选择目标颜色
5. 从结果槽取出合成的色块

### 创造模式标签页

- 打开创造模式物品栏
- 切换到"彩色方块扩展"标签页
- 按色系（A、B、C、D、E、F、G、H、M）浏览全部221种色块

## 合成配方

### 七彩粉末

```
任意原版染料 → 七彩粉末
```

支持全部16种原版染料：白色、橙色、品红色、淡蓝色、黄色、黄绿色、粉色、灰色、淡灰色、青色、紫色、蓝色、棕色、绿色、红色、黑色。

### 色块合成

```
七彩粉末 + 选择颜色 → 对应色块 × 64
```

在方块染色台中操作，七彩粉末放入合成网格，右侧面板选择颜色。

## 技术细节

- 所有色块使用程序染色（BlockColor + ItemColor），无需单独贴图
- 色块ID格式：`mard_pixel:mard_<色号>`（如 `mard_pixel:mard_a1`）
- 七彩粉末ID：`mard_pixel:mard_pigment`
- 方块染色台ID：`mard_pixel:mard_crafting_table`
- 客户端和服务端都需要安装
